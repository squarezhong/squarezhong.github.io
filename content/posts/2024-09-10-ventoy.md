如果你有安装系统或者使用 PE 修复现有系统的需求，那你一定绕不开一件事——制作启动盘。

现在制作启动盘迎来了终极解决方案：VENTOY

VENTOY 的主要优点：

1. 直接放入操作系统 iso 文件即可使用，无需烧录或格式化硬盘
2. 可同时存放多个操作系统（Windows/Linux 均可）
3. U 盘剩余空间仍可正常使用

## 安装

- 参考[官方文档](https://www.ventoy.net/en/doc_start.html)，Windows 和 Linux 都有 GUI 的安装程序，根据指示安装即可。
- macOS 使用 [mactoy](https://github.com/cashcon57/mactoy)，根据 README 完成安装。

## 使用

安装成功后你的 U盘 会有两个分区，小的那个 `VTOYEFI` 是 `/EFI` 分区（Linux 桌面端可能默认不会显示），不要把镜像放在里面！！！

镜像文件可以放在大的那个分区的**任何位置**，你可以可以按照系统类型进行分类，比如 Windows 镜像放入名为 `Windows` 的文件夹，Linux 镜像放入名为 `Linux` 的文件夹。

## 升级

Windows 或 Linux 用户官网[下载](https://www.ventoy.net/en/download.html)对应平台的压缩包，解压后:
- Windows：运行 `Ventoy2Disk.exe`（可能需要管理员权限）
- Linux：
	- 先运行 `lsblk` 找到你安装 Ventoy 的设备，一般是什么 `/dev/sdX`, `X` 是个占位符
	- 查看当前安装的 Ventoy 版本：`sudo Ventoy2Disk.sh -l /dev/sdX`
	- 升级 Ventoy 版本：`sudo Ventoy2Disk.sh -u /dev/sdX`，按照命令行提示操作即可

macOS：使用 [mactoy](https://github.com/cashcon57/mactoy)
